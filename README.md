## 🛠️ Fonctionnalités Clés

### 🔐 Algorithmes Multi-Niveaux
- **AES-256 (Avancé)** : Le standard mondial pour une sécurité impénétrable.
- **Vigenère** : Cryptographie polyalphabétique avec visualisation didactique.
- **César** : Décalage classique pour une initiation ludique.
- **Base64** : Encodage universel pour la transmission de données.

### 🔑 Digital Lab & Gestion des Clés
- **Éducation Responsable** : Apprentissage de la cybersécurité directement dans le menu des clés.
- **Génération Web Crypto** : Clés de 256 bits générées localement (API Web Crypto).
- **Thématiques Gamer** : Passphrases inspirées de *Skyrim*, *Cyberpunk*, *Zelda*, etc.

### 🛡️ Souveraineté & Confidentialité "Zero-Knowledge"
- **Exécution 100% Client-Side** : Aucune donnée ne quitte votre machine.
- **Sobriété Numérique** : Empreinte carbone réduite (pas de serveurs gourmands).
- **PWA Ready** : Installation native sur Android, iOS et Windows.
