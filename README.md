
# 🛡️ AlexCipher - Secure Exchange Suite (2025 Edition)

![AlexCipher Banner](https://img.shields.io/badge/Security-AES--256-cyan?style=for-the-badge&logo=shield)
![AlexCipher Banner](https://img.shields.io/badge/UX-Gamer_Dark_Mode-indigo?style=for-the-badge&logo=shadow)
![AlexCipher Banner](https://img.shields.io/badge/Privacy-100%25_Local-emerald?style=for-the-badge&logo=lock)

**AlexCipher** est une plateforme de cryptage moderne et ultra-sécurisée conçue par **Alexis Mupole**. Alliant une esthétique "Gamer Dark" à des algorithmes de chiffrement de pointe, elle permet de sécuriser vos échanges privés en un clic, tout en éduquant ses utilisateurs au **Numérique Responsable**.

---

## 🚀 Fonctionnalités Clés

### 🔐 Algorithmes Multi-Niveaux
- **AES-256 (Avancé)** : Le standard mondial pour une sécurité impénétrable.
- **Vigenère** : Cryptographie polyalphabétique avec visualisation didactique du flux technique.
- **César** : Décalage classique pour une initiation ludique à la cryptographie.
- **Base64** : Encodage universel pour la transmission de données brutes.

### 🔑 Digital Lab & Gestion des Clés
- **Éducation Responsable** : Une section dédiée à l'apprentissage de la cybersécurité et de la sobriété numérique directement dans le menu des clés.
- **Génération Web Crypto** : Clés de 256 bits générées localement via l'API Web Crypto.
- **Thématiques Gamer** : Passphrases inspirées de *Skyrim (2025 Edition)*, *Cyberpunk*, *Zelda*, et plus encore.

### 🛡️ Souveraineté & Confidentialité "Zero-Knowledge"
- **Exécution 100% Client-Side** : Absolument aucune donnée ne quitte votre machine.
- **Sobriété Numérique** : En traitant tout localement, AlexCipher réduit l'empreinte carbone liée aux transferts serveurs inutiles.
- **Auditabilité** : Code ouvert et transparent disponible sur GitHub.

---

## 🛠️ Stack Technique

- **Frontend** : React 19 + TypeScript.
- **Styling** : Tailwind CSS (Néon UI).
- **Icons** : Lucide React.
- **Crypto** : CryptoJS & Native Web Crypto API.
- **PWA** : Support hors-ligne complet via Service Workers.

---

## 🎮 Expérience Utilisateur (UX)

- **Dashboard Bimodal** : Basculement fluide entre Chiffrement et Déchiffrement.
- **Digital Lab** : Apprenez l'entropie, la protection des données et l'éthique numérique en gérant vos clés.
- **Multi-Langues** : Support natif du Français et de l'Anglais.

## 📖 Installation & Usage

1. **Visitez** : L'application est une PWA, vous pouvez l'installer sur votre mobile.
2. **Choisissez** : Sélectionnez votre algorithme.
3. **Apprenez** : Consultez les conseils du "Digital Lab" pour créer des clés robustes.
4. **Partagez** : Transmettez vos secrets en toute sérénité.
